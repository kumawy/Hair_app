## О приложении

Hair App помогает подобрать стрижку по форме лица, текстуре и длине волос. В приложении можно искать причёски, фильтровать каталог, сохранять избранное и получать рекомендации на основе своего профиля. Сканер предлагает форму лица по фотографии; пользователь подтверждает результат или выбирает параметры вручную.

## Технологии

| Технология | Для чего используется |
| --- | --- |
| **Flutter / Dart** | Общий интерфейс для iOS и Android, светлая и тёмная темы |
| **Riverpod** | Управление состоянием, асинхронная загрузка данных и предоставление зависимостей через провайдеры |
| **GoRouter** | Маршруты приложения и навигация между вкладками с сохранением их состояния |
| **Firebase Authentication** | Регистрация, вход по email и паролю, восстановление пароля |
| **Google Sign-In** | Вход через Google с последующей авторизацией в Firebase |
| **Cloud Firestore** | Хранение имени пользователя и параметров его профиля |
| **SharedPreferences** | Локальное хранение избранного, истории результатов и выбранной темы |
| **Camera / HTTP** | Съёмка и отправка фотографии в отдельный сервис анализа |
| **Apple Vision / Google ML Kit** | Проверка положения лица на устройстве через нативный код Swift и Kotlin |
| **CustomPainter / GLSL** | Отрисовка сетки лица, анимации сканирования и эффектов интерфейса |

## Архитектура

Код организован **по функциональным модулям (feature-first)**: авторизация, профиль, поиск, каталог и сканер находятся в отдельных директориях. Общие настройки приложения вынесены в `core`, переиспользуемые модели и виджеты — в `shared`.

```text
lib/
├── core/                 # Роутер, темы, локальное хранилище
├── features/
│   ├── auth/             # Авторизация и данные пользователя
│   ├── home/             # Главная страница
│   ├── search/           # Поиск и фильтры
│   ├── hairstyles/       # Каталог, карточки и рекомендации
│   ├── favorites/        # Избранное
│   ├── face_scanner/     # Камера, анализ фото и результаты
│   └── profile/          # Профиль, история, настройки и помощь
└── shared/               # Общие модели и виджеты
```

Экраны получают данные и зависимости через **Riverpod**. Репозитории инкапсулируют работу с Firebase и загрузку каталога, а сервисы отвечают за анализ фото и подбор стрижек. Локальное состояние интерфейса, например анимации и поля формы, хранится в виджетах.

Анализ фотографии отделён интерфейсом `FaceAnalysisService`: HTTP-реализацию можно заменить, не меняя контракт экрана. В тестах провайдеры подменяются тестовыми реализациями, чтобы проверять сценарии без реальных аккаунтов и сетевых запросов.

### Данные и хранение

- **Каталог** загружается из `assets/data/hairstyles.json`, фотографии стрижек входят в приложение.
- **Аккаунт и профиль** используют Firebase Auth и Firestore. Сохранение параметров после сканирования выполняется по действию пользователя.
- **Избранное и история** хранятся на устройстве отдельно для каждого аккаунта и гостя. Между устройствами они не синхронизируются; фотографии в историю не записываются.
- **Тема** сохраняется локально и восстанавливается при следующем запуске.

### Сканер и рекомендации

1. Камера показывает подсказки по положению лица. Нативный детектор обрабатывает видеокадры на устройстве.
2. После снимка и нажатия **Analyze photo** приложение отправляет фото в отдельный Python-сервис: `/landmarks` возвращает геометрию лица, `/predict` — предполагаемую форму.
3. Пользователь подтверждает форму лица, указывает текстуру и длину волос.
4. Приложение подбирает стрижки по тегам формы и текстуры из каталога, затем ранжирует их по длине.

Сервер анализа и веса модели находятся вне этого репозитория. Без сервиса доступен ручной выбор параметров. **Preview hairstyle** пока показывает референс из каталога: генерация причёски на фотографии пользователя не подключена.

```sh
flutter analyze
flutter test
python3 -m unittest discover -s tool -p 'test_*.py'
```
